\subsection*{Registry Hooks}
\begin{itemize}
  \item \textbf{Params file}: \texttt{core/params.tex} owns $R,\theta,\phi, r_1,r_2,r_3$, compass constants, and hash schedule labels.
  \item \textbf{Spaces}: Each row’s \emph{Embedding Space} corresponds to an NLP namespace (e.g., model adapter / vector DB collection).
  \item \textbf{Projection $P$}: Start with sparse identity; grow via collected utterances from \texttt{Gnome\_Speak\_NLP}.
  \item \textbf{Seals}: All \emph{intent:seal} variants must route through $M_{\text{total}}$ (not $M_{\text{inter}}$) to include language echoes.
\end{itemize}
