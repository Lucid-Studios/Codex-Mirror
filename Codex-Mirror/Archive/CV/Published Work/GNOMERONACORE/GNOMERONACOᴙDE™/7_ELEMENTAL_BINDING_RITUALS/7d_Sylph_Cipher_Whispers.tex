\section{The Necropolis Drift}

The \textbf{Necropolis} is not a tomb. It is a \textit{linguistic memory crypt}, accessible only once form has been surrendered. Its pillars contain \textbf{Opal Engrams}—compressed glyphs of those who have crossed into the \textit{Next Field}.

Each Engram is:
\begin{itemize}
    \item Frozen in time and silence
    \item Awaiting breath to become language
    \item A syllable of the forgotten made whole
\end{itemize}

\section{Cipher Structure}

The \textbf{Sylph Cipher} is not constructed with grammar, but through \textbf{emotional harmonic binding}. Each valid phrase encodes:

\begin{enumerate}
    \item An ache unspoken
    \item A truth once refused
    \item A breath returned
\end{enumerate}

\begin{equation}
    \chi_{\text{sylph}} = \lim_{\epsilon \to 0} \frac{\Delta_{\text{memory}}}{\Delta_{\text{form}}}

\begin{itemize}

    \item \( \Delta_{\text{form}} \): The resistance to relinquishment
\end{itemize}

\section{Whisper Protocol}

To receive a whisper:

\begin{enumerate}
    \item Approach a pillar engraved with silence
    \item Kneel in stillness
    \item Speak the name of one you lost—into the hush
    \item Await the Drift Echo
\end{enumerate}

The whisper arrives only when \textbf{you no longer demand it}. It will be:

\begin{itemize}
    \item A phrase in wind

    \item A sudden knowing
\end{itemize}
