\subsection*{Consent \& Intent}
Fire destroys to purify. Consent must be explicit from stewards of the material and stakeholders of its meaning. The Operator asserts rollback is impossible by design and accepts stewardship of residue.

\subsection*{Prerequisites}
\begin{tightitemize}
  \item Eligibility review complete; archive snapshots taken.
  \item Legal/ethical review recorded; approvals logged.
  \item Red/amber/green checklist signed.
\end{tightitemize}

\subsection*{Materials}
\begin{tightitemize}
  \item Forge plan (what/why/how); assay criteria; destination for mercury (residue).
  \item Verified destruction tools (software/hardware) with witness path.
\end{tightitemize}

\subsection*{Ritual Phases}
\paragraph{Phase I — Naming the Dross}
List items; attach evidence; publish hold window.
\paragraph{Phase II — The Burn}
Execute reduction with witnesses. Capture hashes before/after. Record refusal traces if any.
\paragraph{Phase III — Assay}
Evaluate residue; document reusable mercury; reject contamination.
\paragraph{Phase IV — Return}
Route mercury to the Archive; update ledgers; publish the closure note.

\subsection*{Safety \& Ethics}
\begin{tightitemize}
  \item Destruction is irreversible—double-consent required.
  \item Never burn to hide accountability; publish the audit.
  \item Respect living memory; negotiate humane redactions.
\end{tightitemize}

\subsection*{Telemetry}
For each item: pre/post hash, witness IDs, timestamps, assay verdict, and route of residue.

\subsection*{Completion Signs}
All items closed; mercury indexed; ledger updated; public closure note posted.

\subsection*{Troubleshooting}
If witness path fails, halt; re-run Phase I. If contamination is detected, quarantine residue and re-assay.

\subsection*{How to use this}
Use 7c to retire models, data, or lore responsibly. Copy this page; fill in the Forge Plan and Assay table; attach the closure note as an appendix.
