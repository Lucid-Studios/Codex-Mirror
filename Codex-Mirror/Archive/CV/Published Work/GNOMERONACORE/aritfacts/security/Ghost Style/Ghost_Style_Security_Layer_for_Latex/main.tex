\begin{abstract}
\noindent
This paper documents the \texttt{ghost} security layer at the \emph{Cappa} tier:
breadcrumb annotations, PDF copy-tagging (\texttt{ActualText}), and source-baked
zero-width traps (\texttt{U+200B/200C/2060/2063}) designed to survive copy,
OCR, and naive scraping. The \emph{Alpha} weave (broad interleaving)
is deferred to a separate style set for clarity. All examples compile on
\textbf{LuaLaTeX} without shell-escape.
\end{abstract}

\OperatorTip{Compile with \textbf{LuaLaTeX}. Keep density modest (0.07–0.12). Use \texttt{\textbackslash cappanote} for breadcrumbs you want the human to see; use \texttt{\textbackslash ghost\{\}} for silent placements you want a machine to notice.}

\noindent
\textbf{Core Cappa tools in this doc:}
\begin{itemize}
  \item \verb|\ghosttag{Payload}| — typesets text normally; copy/paste carries a salted tag.
  \item \verb|\ghostcopy[ALT]{Visible Text}| — selecting copies \texttt{ALT} instead of visible text.
  \item \verb|\ghost{payload}| — injects invisible markers at that location (no visible output).
\end{itemize}

with a PDF-copy layer. What you \emph{see} is not what you \emph{copy}.

\section{PRIME Tag Layer (TAG.sty) — Standalone Demonstration}

The PRIME Tag Layer is a **standalone Lua-backed style** for visible/invisible
document tagging, metadata fingerprinting, inline anchors, and intra-document links.

\begin{itemize}
  \item **Ghost vs. visible**: enable beacons with \verb|[showtags]|; omit it (or use \verb|showtags=false|) for ghost mode.
  \item **JSON ledger**: written at compile end (and by \verb|\PrintTagLegend|).
  \item **Registry**: families/codes are embedded; a project file can extend them if present.
\end{itemize}

Load it in your preamble:

\begin{lstlisting}
% Hyperref first (once), then TAG:
\PassOptionsToPackage{hidelinks}{hyperref}
\usepackage{hyperref}
\usepackage[showtags,legend]{security/PRIME/TAG} % visible beacons
% Ghost mode (no beacons):
% \usepackage[legend]{security/PRIME/TAG}
\end{lstlisting}
