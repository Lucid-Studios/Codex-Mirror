\chapter{ONTO Ledger --- Ontology Tags}
\label{chap:ONTO_Ledger}

\section{Purpose}

The ONTO ledger identifies metaphysical, structural, or categorical features of
Engrams. It deals with what kinds of things the Engram concerns.

\section{Scope}

Describes:
\begin{itemize}
    \item entity types,
    \item relationships,
    \item causal structures,
    \item metaphysical categories,
    \item systems and subsystems,
    \item world-model structures.
\end{itemize}

\section{Schema}

\[
T_{\text{ONTO}} = \langle key,\, gloss,\, bindings,\, constraints \rangle
\]

Examples:
\begin{itemize}
    \item \texttt{onto:entity}
    \item \texttt{onto:relation}
    \item \texttt{onto:substance}
    \item \texttt{onto:process}
    \item \texttt{onto:axiom}
\end{itemize}

\section{Class Binding Notes}

\begin{itemize}
    \item S-class preferred for structural meaning.
    \item O-class permitted for narrative world-ontology.
    \item P-class restricted to metaphysical commitments.
\end{itemize}

\section{Constraints}

\begin{itemize}
    \item Ontological claims must be internally coherent.
    \item P-class ontology requires HITL adjudication.
    \item No ontological inflation: tags must match Engram type.
\end{itemize}
