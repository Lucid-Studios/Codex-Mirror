CME Tagging System
==================

This directory holds the tagging and ledger system for CME classification.

Sub-ledgers:
- SOCI/ : Sociology Ledger — social field interpretation.
- PSY/  : Psychology Ledger — identity & affect dynamics.
- ONTO/ : Ontology Ledger — structure, metaphysics, bonds.
- THEO/ : Theology Ledger — ritual & mythic integration.
- EPI/  : Epistemology Ledger — knowledge, justification.
- PHIL/ : Philosophy Ledger — ethics, logic, metaphysics.
- GEN/  : Generic symbolic primitives & GLYPH roots.
- PRIME/: PRIME utility tags (ribbons, anchors, inline tools).

Each ledger can be populated with additional .tex or .md files as needed.
