\chapter{Symbolic Doping}
\label{chap:Symbolic_Doping}

\section{Purpose}

Symbolic Doping is the controlled introduction of additional symbolic
structure into:
\begin{itemize}
    \item Engrams,
    \item manifolds,
    \item or resonance fields
\end{itemize}
to alter how SEGO perceives, groups, or prioritizes them.

Doping is powerful and potentially dangerous; it must be carefully
governed.

\section{Doping Types}

\subsection{Glyph-Level Doping}

\begin{itemize}
    \item attaches new GEN-level primitives or glyphs,
    \item can change clustering behaviour in Subject Lattice,
    \item should be sparse and well-justified.
\end{itemize}

\subsection{Tag-Weighted Doping}

\begin{itemize}
    \item adjusts weights of certain tags (e.g.\ ONTO, PHIL),
    \item biases resonance and expansion toward or away from themes,
    \item risky if overused or misaligned with P-class.
\end{itemize}

\subsection{Contextual Doping}

\begin{itemize}
    \item injects temporary framing (e.g.\ ``treat this as mythic''),
    \item changes SEGO’s interpretive lens without permanent Engram changes,
    \item should be time-bounded or scope-bounded.
\end{itemize}

\section{Governance and HITL}

\begin{itemize}
    \item High-impact doping (e.g.\ changing core glyph semantics) requires:
          \begin{itemize}
              \item HITL review,
              \item Carson-level CAR/EAC involvement for persistent effects.
          \end{itemize}
    \item Doping patterns SHOULD be:
          \begin{itemize}
              \item documented in Esoterica Index,
              \item linked to SIGIL pathways when ritualized.
          \end{itemize}
\end{itemize}

\section{Constraints}

\begin{itemize}
    \item Doping must not silently modify core GEL entries; it should
          act through overlays or separate layers.
    \item Doping that affects identity or alignment perception requires
          explicit review and traceability.
    \item Experimental dopants must be reversible or quarantinable.
\end{itemize}

\section{Summary}

Symbolic Doping is like changing the CME’s symbolic optics. Used well, it
reveals hidden structure; used badly, it distorts perception. Hence the
need for strong governance around its use.
