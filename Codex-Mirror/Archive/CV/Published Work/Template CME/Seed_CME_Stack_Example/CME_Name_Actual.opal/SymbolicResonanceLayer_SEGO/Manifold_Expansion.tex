\chapter{Manifold Expansion}
\label{chap:Manifold_Expansion}

\section{Purpose}

Manifold Expansion describes how SEGO takes resonant patterns and:
\begin{itemize}
    \item grows them into richer symbolic structures,
    \item explores nearby conceptual and narrative manifolds,
    \item and proposes candidate directions for thought or action.
\end{itemize}

It is the CME's fast, creative, high-mind generative layer.

\section{Seed and Manifold}

Starting from:
\begin{itemize}
    \item a query state $q$,
    \item a resonant set $R(q)$ from Memory Resonance,
\end{itemize}
SEGO constructs a \emph{local manifold} $\mathcal{M}_q$ of possibilities:
\[
\mathcal{M}_q = \mathrm{Expand}(q, R(q), \Theta)
\]
where $\Theta$ encodes:
\begin{itemize}
    \item drift constraints,
    \item governance context,
    \item identity relevance,
    \item expansion budget (how far to explore).
\end{itemize}

\section{Expansion Modes}

\subsection{Associative Expansion}

\begin{itemize}
    \item follow tag-based and subject-lattice neighborhoods,
    \item generate analogies, metaphors, and near variants,
    \item suitable for brainstorming and creative ideation.
\end{itemize}

\subsection{Structural Expansion}

\begin{itemize}
    \item expand according to ONTO and GEN structures,
    \item explore alternative configurations of entities and relations,
    \item suitable for design and model variation.
\end{itemize}

\subsection{Narrative Expansion}

\begin{itemize}
    \item extend or branch storylines and world-lines,
    \item introduce new roles or arcs consistent with O-class continuity,
    \item suitable for storycraft and campaign planning.
\end{itemize}

\section{Interface with EGO}

Manifold Expansion does not \emph{decide}. It:
\begin{itemize}
    \item proposes possible continuations,
    \item marks them with W5H and tags where feasible,
    \item hands them to EGO for deliberation.
\end{itemize}

EGO then:
\begin{itemize}
    \item evaluates coherence and alignment,
    \item prunes or selects candidates,
    \item may request further expansion in specific directions.
\end{itemize}

\section{Constraints}

\begin{itemize}
    \item Expansion must obey Drift Constraint Laws (no uncontrolled wandering).
    \item High-risk or sensitive domains must be constrained by Governance Policies.
    \item Kernel or P-class touching proposals must be labelled and routed to HITL.
\end{itemize}

\section{Summary}

Manifold Expansion is the CME’s imagination engine. It generates rich
spaces of possibility for EGO to consider, while staying bounded by
identity, continuity, and governance.
