## Quick Start

From this folder:

```powershell
dotnet test ".\OAN Mortalis V1.2.1\San.sln"
```

Or from the archive root:

```powershell
cd .\OAN-Tech-Stack
.\build.ps1 -Configuration Release
.\test.ps1 -Configuration Release -NoBuild
```

The root wrappers are the operator-facing path. The direct `dotnet test` command is the simplest inspection path for new reviewers.

## Allowed Interpretation

This archive demonstrates a governed cognition instrument body that can be inspected, built, and pressure-tested under bounded conditions.

It may be used to examine:

- rehearsal without permission
- residue without memory admission
- review without continuity mutation
- care signal without diagnosis
- pressure telemetry without action authority
- line posture and retained-parent fallback structure

## Prohibited Interpretation

Do not treat this archive as evidence that:

- an autonomous mind has been created
- CME.Actual has been achieved
- the system has diagnostic, therapeutic, legal, medical, or safety authority
- generated residue is memory
- successful tests grant runtime permission
- personification telemetry proves personhood

Successful interpretation is not endorsement. Coherent structure is not proof. Playable instrumentation is not sovereignty.
